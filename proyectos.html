Proyectos

Una selección de los proyectos que he desarrollado.

CiberDino

CiberDino es un sitio web creado para enseñar a las personas cómo cuidar su seguridad en internet. Reúne estrategias claras y fáciles de aplicar para protegerse de riesgos comunes en la red, como contraseñas débiles, estafas y robo de información.

Además, cuenta con un asistente virtual al que el usuario puede hacerle cualquier pregunta, para resolver dudas de forma rápida y sencilla.

Funciones principales:

  • Estrategias y consejos de seguridad en internet
  • Asistente virtual para resolver cualquier pregunta

AgroGest

AgroGest es un sitio web para la gestión y el control de un negocio agropecuario. Permite tener organizada la información del día a día en un solo lugar, para que el productor tome mejores decisiones.

Funciones principales:

  • Consulta del stock disponible
  • Visualización de los productos
  • Control de ventas
  • Control de pedidos
